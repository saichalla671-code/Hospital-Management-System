
# Hospital Management System

## Project Overview
A full-stack Hospital Management System developed using Java Spring Boot, React.js and MySQL.

## Technologies Used

### Backend
- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- JWT Authentication
- MySQL

### Frontend
- React.js
- JavaScript
- HTML
- CSS
- Axios
- React Router

## Main Modules
1. Patient Management
2. Doctor Management
3. Department Management
4. Appointment Management
5. Prescription Management
6. Billing Management
7. User Registration and Login
8. Role-Based Authentication
9. Dashboard and Reports

## User Roles
- ADMIN
- DOCTOR
- PATIENT

## Main Features
- Add, update, view and delete records
- Secure login using JWT
- Password encryption
- Role-based access control
- Appointment management
- Billing and invoice generation
- Dashboard statistics
- PDF reports

## How to Run

### Backend
1. Open the backend in IntelliJ IDEA.
2. Configure MySQL database.
3. Run the Spring Boot application.

### Frontend
1. Open the frontend folder.
2. Run npm install.
3. Run npm run dev.
